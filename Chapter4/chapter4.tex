\section{Lựa chọn công nghệ}

\subsection{Công nghệ Frontend}

Để phát triển giao diện người dùng có tính tương tác cao và phản hồi nhanh, các công nghệ sau đã được lựa chọn:
\begin{itemize}
    \item \textbf{ReactJS}: Thư viện Javascript phổ biến cho phép xây dựng giao diện dạng Single Page Application (SPA), giúp tối ưu hóa hiệu năng render trang thông qua Virtual DOM và tái sử dụng các thành phần giao diện (components).
    \item \textbf{TypeScript}: Ngôn ngữ mở rộng của JavaScript bổ sung cơ chế kiểm soát kiểu dữ liệu tĩnh (static typing), giúp phát hiện lỗi sớm trong quá trình biên dịch và tăng độ tin cậy của mã nguồn khi hệ thống mở rộng.
    \item \textbf{Tailwind CSS}: Khung CSS tiện ích (utility-first) giúp xây dựng giao diện nhanh chóng, đảm bảo tính nhất quán của hệ thống thiết kế (Design System) và hỗ trợ tốt thiết kế đáp ứng (Responsive).
    \item \textbf{Recharts}: Thư viện trực quan hóa dữ liệu dựa trên SVG được tối ưu riêng cho React, dùng để vẽ các biểu đồ xu hướng tuyển dụng, mức lương và biểu đồ radar so khớp kỹ năng.
\end{itemize}

\subsection{Công nghệ Backend \& Database}

\begin{itemize}
    \item \textbf{FastAPI (Python)}: Khung phát triển web hiện đại, hiệu năng cao dựa trên nền tảng ASGI, hỗ trợ lập trình bất đồng bộ (async/await) và tự động tạo tài liệu API chuẩn OpenAPI (Swagger UI).
    \item \textbf{PostgreSQL}: Cơ sở dữ liệu quan hệ mạnh mẽ dùng để lưu trữ các thông tin có tính toàn vẹn cao như tài khoản người dùng, hồ sơ CV đã phân tích, từ điển kỹ năng nghề nghiệp và kết quả so khớp.
    \item \textbf{MongoDB}: Cơ sở dữ liệu NoSQL dạng tài liệu (document-oriented) dùng để lưu trữ tạm thời dữ liệu tin tuyển dụng thô (raw JSON) thu thập từ các trang web trước khi tiến hành chuẩn hóa.
\end{itemize}

\subsection{Công nghệ Thu thập \& Xử lý AI}

\begin{itemize}
    \item \textbf{Scrapy}: Khung thu thập dữ liệu (Web Crawling) mạnh mẽ của Python, hỗ trợ xử lý đa luồng bất đồng bộ, giúp cào dữ liệu tin tuyển dụng quy mô lớn một cách nhanh chóng và ổn định.
    \item \textbf{SentenceTransformers}: Thư viện Python dựa trên PyTorch dùng để tạo các vector nhúng (embeddings) chất lượng cao cho các kỹ năng và cụm từ chuyên môn từ mô hình pre-trained \texttt{all-MiniLM-L6-v2}.
    \item \textbf{Gemini API / OpenAI API}: Sử dụng mô hình ngôn ngữ lớn (LLM) thông qua API để thực hiện trích xuất thông tin thực thể (kỹ năng, chức danh) từ văn bản mô tả công việc (JD) và CV không cấu trúc.
\end{itemize}

\section{Xây dựng pipeline tổ chức dữ liệu}

\subsection{Cài đặt các module thu thập dữ liệu tin tuyển dụng tự động}

Quy trình thu thập dữ liệu tuyển dụng được cài đặt bằng Scrapy. Dưới đây là mã nguồn minh họa một module crawler thu thập tin tuyển dụng thô từ trang web:

\begin{lstlisting}[language=Python, caption=Ma nguon Scrapy Spider thu thap tin tuyen dung]
import scrapy
from crawler.items import JobItem

class JobSpider(scrapy.Spider):
    name = "job_spider"
    allowed_domains = ["example-recruitment.com"]
    start_urls = ["https://example-recruitment.com/jobs"]

    def parse(self, response):
        for job_card in response.css(".job-card"):
            item = JobItem()
            item['title'] = job_card.css(".job-title::text").get().strip()
            item['company'] = job_card.css(".company-name::text").get().strip()
            item['location'] = job_card.css(".location::text").get().strip()
            detail_url = job_card.css("a::attr(href)").get()
            yield response.follow(detail_url, self.parse_detail, cb_kwargs={'item': item})

    def parse_detail(self, response, item):
        item['description'] = " ".join(response.css(".job-description *::text").getall())
        item['salary'] = response.css(".salary::text").get()
        yield item
\end{lstlisting}

\subsection{Quy trình làm sạch dữ liệu, xử lý trùng lặp và lưu trữ vào PostgreSQL}

Sau khi dữ liệu thô được lưu vào MongoDB, pipeline xử lý dữ liệu (ETL pipeline) sẽ thực hiện làm sạch và lọc trùng lặp:
\begin{enumerate}
    \item \textbf{Lọc trùng lặp vật lý}: Tính mã băm SHA-256 từ chuỗi nối của ba trường thông tin: \texttt{title + company + location}. Nếu mã hash đã tồn tại trong PostgreSQL, bản ghi sẽ bị loại bỏ.
    \item \textbf{Xử lý ngôn ngữ thô}: Loại bỏ các thẻ HTML còn sót lại, chuẩn hóa dấu câu và đưa văn bản về định dạng chữ thường.
    \item \textbf{Trích xuất và chuẩn hóa kỹ năng}: Gọi module xử lý AI để chuyển đổi văn bản thô thành danh sách kỹ năng chuẩn trước khi lưu trữ vào PostgreSQL.
\end{enumerate}

\section{Xây dựng chức năng cho các phân hệ người dùng}

\subsection{Hiện thực hóa các tính năng Quản lý tài khoản, Đăng ký/Đăng nhập (Auth)}

Hệ thống sử dụng cơ chế bảo mật JWT (JSON Web Token):
\begin{itemize}
    \item Khi người dùng đăng nhập thành công, Backend tạo ra một mã JWT chứa thông tin định danh và vai trò (\texttt{role}). Mã này được ký bằng thuật toán mã hóa đối xứng HS256 với khóa bí mật.
    \item Token được gửi về Frontend và lưu vào \texttt{localStorage} hoặc HTTP-only Cookie.
    \item Đối với các API yêu cầu bảo mật (như tải CV hoặc lưu việc làm), Frontend đính kèm token trong Header \texttt{Authorization: Bearer <token>}.
\end{itemize}

\subsection{Hiện thực hóa chức năng Tìm kiếm job, Lưu job và Quản lý danh sách CV}

\begin{itemize}
    \item \textbf{Tìm kiếm Job}: Sử dụng Elasticsearch làm công cụ tìm kiếm chính. Khi người dùng nhập từ khóa tìm kiếm, API Backend chuyển tiếp truy vấn thành cấu trúc câu lệnh DSL của Elasticsearch hỗ trợ tìm kiếm mờ (Fuzzy Search) để tìm kiếm các job phù hợp nhất.
    \item \textbf{Quản lý danh sách CV}: Ứng viên có thể quản lý nhiều phiên bản CV khác nhau, thực hiện đổi tên, xóa, hoặc chọn một CV làm mặc định để đối soát.
\end{itemize}

\subsection{Cài đặt mã nguồn để tính toán độ phù hợp và liệt kê các kỹ năng còn thiếu}

Dưới đây là mã nguồn Python hiện thực hóa giải thuật tính điểm so khớp và xác định kỹ năng khuyết thiếu (Skill Gap):

\begin{lstlisting}[language=Python, caption=Ma nguon xu ly so khop va tinh khoang cach ky nang]
import numpy as np
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')

def cosine_similarity(v1, v2):
    return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))

def analyze_skill_gap(cv_skills, job_skills, threshold=0.82):
    matched_skills = []
    missing_skills = []
    partial_match_scores = 0.0

    # Convert skills to embeddings
    cv_embeddings = model.encode(cv_skills) if cv_skills else []
    
    for job_skill in job_skills:
        # Check for exact matches
        if job_skill.lower() in [s.lower() for s in cv_skills]:
            matched_skills.append({"skill": job_skill, "match_type": "exact", "score": 1.0})
            continue
        
        # Semantic matching for remaining skills
        if len(cv_embeddings) > 0:
            job_skill_emb = model.encode(job_skill)
            max_score = 0.0
            best_match_skill = None
            for idx, cv_skill in enumerate(cv_skills):
                sim = cosine_similarity(job_skill_emb, cv_embeddings[idx])
                if sim > max_score:
                    max_score = sim
                    best_match_skill = cv_skill
            
            if max_score >= threshold:
                matched_skills.append({
                    "skill": job_skill, 
                    "match_type": "semantic", 
                    "score": float(max_score),
                    "matched_with": best_match_skill
                })
                partial_match_scores += max_score
                continue
        
        # No match found
        missing_skills.append(job_skill)

    # Compute final matching score
    total_required = len(job_skills)
    exact_count = len([s for s in matched_skills if s["match_type"] == "exact"])
    
    match_score = 0.0
    if total_required > 0:
        match_score = (exact_count + partial_match_scores) / total_required * 100
        match_score = min(100.0, float(match_score))

    return {
        "match_score": round(match_score, 2),
        "matched_skills": matched_skills,
        "missing_skills": missing_skills
    }
\end{lstlisting}

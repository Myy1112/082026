\chapter{Thiết kế Khung thu thập và Phân tích dữ liệu thị trường lao động}
\label{Chapter3}

\section{Kiến trúc tổng thể khung dữ liệu}

Kiến trúc tổng thể khung dữ liệu CareerLens bao gồm ba phân hệ chính: (1) phân hệ thu thập dữ liệu, (2) phân hệ xử lý và chuẩn hóa, (3) phân hệ API và trực quan hóa. Các phân hệ này hoạt động theo quy trình ETL (Extract, Transform, Load) và được triển khai trên một kiến trúc microservices để đảm bảo tính mở rộng và độ tin cậy.

\section{Phân hệ thu thập dữ liệu đa nguồn}

\subsection{Luồng xử lý thu thập dữ liệu tuyển dụng không cấu trúc}

Phân hệ thu thập sử dụng kỹ thuật Web Scraping kết hợp với API Integration:

\begin{enumerate}
    \item \textbf{Web Scraping}: Sử dụng Scrapy framework để crawl các trang web tuyển dụng.
    \item \textbf{API Integration}: Kết nối với LinkedIn API, Indeed API để lấy dữ liệu có cấu trúc.
    \item \textbf{Scheduling}: Sử dụng Apache Airflow để lập lịch chạy hàng ngày.
    \item \textbf{Storage}: Lưu dữ liệu thô vào MongoDB (NoSQL) để xử lý sau.
\end{enumerate}

\subsection{Mô hình hóa cấu trúc dữ liệu việc làm tổng hợp}

Dữ liệu công việc được mô hình hóa với các trường chính:
\begin{itemize}
    \item Job ID, Title, Company, Location
    \item Description (text), Requirements, Skills
    \item Salary, Contract Type, Seniority Level
    \item Source, Posting Date, Crawl Date
\end{itemize}

\section{Phân hệ xử lý và chuẩn hóa dữ liệu}

\subsection{Thuật toán nhận diện và khử trùng lặp thông tin việc làm}

Để phát hiện công việc trùng lặp từ các nguồn khác nhau, sử dụng:

\begin{enumerate}
    \item \textbf{Hashing}: Tính hash SHA-256 của title + company + location
    \item \textbf{Fuzzy Matching}: Sử dụng Levenshtein distance để tìm các công việc gần giống nhau
    \item \textbf{Similarity Threshold}: Công việc có độ tương đồng > 90\% được coi là trùng lặp
\end{enumerate}

\subsection{Cơ chế chuẩn hóa thuộc tính và phân loại danh mục kỹ năng nghề nghiệp}

Sử dụng các kỹ thuật NLP:

\begin{itemize}
    \item \textbf{Text Cleaning}: Loại bỏ diacritics, ký tự đặc biệt, chuẩn hóa khoảng trắng
    \item \textbf{Skill Extraction}: Sử dụng NER (Named Entity Recognition) để trích xuất các kỹ năng
    \item \textbf{Skill Normalization}: Ánh xạ các tên kỹ năng khác nhau về cùng một tiêu chuẩn
    \item \textbf{Skill Taxonomy}: Xây dựng bộ phân loại kỹ năng theo các danh mục (Backend, Frontend, DevOps, etc.)
\end{itemize}

\section{Mô hình API phục vụ trực quan hóa dữ liệu xu hướng}

API được thiết kế theo tiêu chuẩn RESTful:

\begin{itemize}
    \item \texttt{GET /api/v1/jobs}: Lấy danh sách công việc với bộ lọc
    \item \texttt{GET /api/v1/skills/trending}: Lấy top kỹ năng theo xu hướng
    \item \texttt{GET /api/v1/salary-analysis}: Phân tích lương theo vị trí, ngành
    \item \texttt{POST /api/v1/cv-analysis}: Phân tích CV và Skill Gap Analysis
\end{itemize}
